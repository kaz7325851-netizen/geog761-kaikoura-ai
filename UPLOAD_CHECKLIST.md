# Publication and update checklist

Repository: https://github.com/kaz7325851-netizen/geog761-kaikoura-ai
The owner requested public visibility. This checklist applies to the initial
code snapshot and all later updates; it does not certify external asset rights.

1. Confirm the team's contribution permissions and choose a repository licence.
   Upstream attribution/licence review remains necessary even for a private repo.
2. Upload the contents of this folder, not the parent `testdata` directory.
   Alternatively extract the code-only ZIP and upload its contents.
3. Do not upload `qa_local/`, `.venv/`, raw imagery, inventory shapefiles,
   checkpoints, cached downloads, cookies, authentication files or temporary URLs.
   `.gitignore` is a safeguard, not a substitute for reviewing the actual file list.
4. Read `README.md`, `docs/sources.md` and `experiments/README.md` before claiming
   reproducibility. The portable VV CLI and archived research scripts have
   different validation levels.
5. Share this repository as research code and data-preparation progress, not a
   trained RF, verified road-passability system or operational response tool.

The code-only ZIP excludes local QA outputs. The packaging provenance records
source hashes and checks; it does not grant rights to third-party assets.
